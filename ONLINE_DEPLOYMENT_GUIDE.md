# 🌐 POS PLUS — Online Cloud Hosting & Multi-Device Sync Guide

This guide walks you through hosting **POS PLUS** online so you and your staff can access it from any phone, tablet, laptop, or desktop computer worldwide with real-time multi-counter synchronization.

---

## 🚀 Option 1: Deploy to Vercel (Recommended — Free & Fast)

Vercel provides free global hosting with automatic SSL (`https://`), high speed CDN, and custom domain support.

### Step 1: Push Project to GitHub
1. Create a free account at [github.com](https://github.com) if you haven't already.
2. Initialize and push this `POS PLUS` folder to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial POS PLUS release"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/pos-plus.git
   git push -u origin main
   ```

### Step 2: Import into Vercel
1. Log in to [vercel.com](https://vercel.com) using your GitHub account.
2. Click **"Add New..."** &rarr; Select **"Project"**.
3. Locate your `pos-plus` repository and click **"Import"**.
4. Vercel automatically detects **Vite** framework (the preset `vercel.json` is already configured for you).
5. Click **"Deploy"**.

✨ Within 30 seconds, your POS is live at:
`https://pos-plus-yourshop.vercel.app`

---

## ⚡ Option 2: Deploy to Netlify (Drag & Drop — No Git Required)

If you don't want to use Git, you can deploy in 60 seconds with drag & drop:

1. In your `POS PLUS` folder, build the production files:
   ```bash
   npm run build
   ```
   *(This creates a production-ready `dist` folder).*
2. Open [app.netlify.com/drop](https://app.netlify.com/drop) in your browser.
3. Drag and drop the **`dist`** folder onto the Netlify webpage.
4. Netlify will deploy your website immediately and give you a free live URL (e.g. `https://peaceful-apparel-pos.netlify.app`).
5. You can rename the site or connect your own custom domain in Netlify Site Settings.

## ☁️ Setting Up Real-Time Multi-Device Cloud Sync (Supabase)

To allow **Counter 1**, **Counter 2**, and your **Mobile Phone** to share the exact same inventory and sales in real time:

### Step 1: Create a Free Supabase Project
1. Go to [supabase.com](https://supabase.com) and sign up for free.
2. Click **"New Project"**, name it (e.g. `Clothing-POS`), and set a database password.
3. Choose the region closest to your shop (e.g. `Mumbai (ap-south-1)` for India).

### Step 2: Run the 1-Click Database Setup Script
1. In your Supabase dashboard, click **SQL Editor** on the left menu.
2. Click **"New query"**.
3. In **POS PLUS**, open **Store Settings** &rarr; Click **"Copy Supabase SQL Setup Script"** (or copy from below):

```sql
-- 1. Clothing Products Table
create table if not exists public.products (
  id bigint generated by default as identity primary key,
  name text not null,
  brand text,
  category text,
  gender text,
  material text,
  hsn text default '6205',
  tax_rate numeric default 5,
  description text,
  variants jsonb default '[]'::jsonb,
  updated_at timestamp with time zone default timezone('utc'::text, now())
);

-- 2. Customers & Khata Ledger Table
create table if not exists public.customers (
  id bigint generated by default as identity primary key,
  name text not null,
  phone text unique not null,
  email text,
  address text,
  gstin text,
  loyalty_points numeric default 0,
  credit_balance numeric default 0,
  total_spent numeric default 0,
  visit_count integer default 0,
  updated_at timestamp with time zone default timezone('utc'::text, now())
);

-- 3. Invoices & Sales Table
create table if not exists public.sales (
  id bigint generated by default as identity primary key,
  invoice_no text unique not null,
  date timestamp with time zone default timezone('utc'::text, now()),
  counter_name text default 'Counter 1',
  customer_name text,
  customer_phone text,
  customer_gstin text,
  items jsonb not null,
  subtotal numeric not null,
  taxable_subtotal numeric,
  total_cgst numeric,
  total_sgst numeric,
  total_igst numeric,
  total_tax numeric,
  bill_discount numeric default 0,
  round_off numeric default 0,
  net_total numeric not null,
  payment_method text not null,
  payment_details jsonb,
  tendered_amount numeric,
  change_amount numeric,
  loyalty_points_earned numeric default 0,
  loyalty_points_redeemed numeric default 0,
  status text default 'completed'
);

-- 4. Returns & Exchanges Table
create table if not exists public.returns (
  id bigint generated by default as identity primary key,
  return_no text unique not null,
  original_invoice_no text,
  date timestamp with time zone default timezone('utc'::text, now()),
  customer_name text,
  customer_phone text,
  items jsonb not null,
  reason text,
  refund_method text,
  refund_amount numeric not null,
  credit_note_code text
);

-- Enable RLS and Realtime
alter table public.products enable row level security;
alter table public.customers enable row level security;
alter table public.sales enable row level security;
alter table public.returns enable row level security;

create policy "Public Products Access" on public.products for all using (true) with check (true);
create policy "Public Customers Access" on public.customers for all using (true) with check (true);
create policy "Public Sales Access" on public.sales for all using (true) with check (true);
create policy "Public Returns Access" on public.returns for all using (true) with check (true);

alter publication supabase_realtime add table public.products, public.customers, public.sales, public.returns;
```
4. Paste the SQL into Supabase and click **Run**. It will take 5 seconds to configure all tables.

### Step 3: Connect POS PLUS to Your Cloud Database
1. In Supabase, go to **Project Settings** &rarr; **API**.
2. Copy your **Project URL** (e.g. `https://xyzabc.supabase.co`) and **anon public API Key**.
3. In **POS PLUS**, go to **Store Settings** &rarr; **Real-Time Multi-Device Cloud Sync**:
   - Check **"Enable Cloud Sync"**
   - Set Terminal Name: `Counter 1` (or `Counter 2` on your second machine)
   - Paste **Project URL** and **Anon Key**
   - Click **"Test Cloud Connection"** &rarr; Should show: `✓ Connected successfully to Cloud Database!`
   - Click **"Push Local Stock & Customers to Cloud"** to sync your initial products.
   - Click **"Save Configuration"**.

## 📱 Accessing from Mobile Phones & Tablets

Once hosted on Vercel or Netlify:
1. Open your URL (e.g. `https://pos-plus-yourshop.vercel.app`) on your iPhone, iPad, or Android phone.
2. In Chrome or Safari, tap the browser menu &rarr; **"Add to Home Screen"**.
3. An app icon named **POS PLUS** will be added to your home screen! It opens like a native mobile app.
4. As the store owner, you can view today's total sales, UPI collections, and cash drawer in real time from home while your staff bills at the shop counter!
